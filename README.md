# 🍫 Projeto de Compra de Doces

Projeto desenvolvido em C++ para simular um pequeno sistema de compra de doces.

O projeto foi desenvolvido com o objetivo de praticar conceitos de Programação Orientada a Objetos (POO), organização de código e utilização de classes.

## 📌 Funcionalidades

- Visualização do catálogo de doces
- Escolha de produtos
- Adição de produtos ao carrinho
- Compra de vários doces
- Cálculo automático do valor total
- Validação das opções escolhidas
- Exibição do resumo da compra

## 🍬 Produtos disponíveis

Atualmente o catálogo possui:

- Palha Italiana
- Brownie
- Brigadeiro

## 🛠️ Tecnologias utilizadas

- C++
- Programação Orientada a Objetos
- STL (`vector`)
